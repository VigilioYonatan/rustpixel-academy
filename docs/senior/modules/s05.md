# S05 · Frontera FFI frágil

**Tipo:** reto guiado Senior Rust · **ID:** S05-C01 · **Estado:** material práctico preparado; no prueba de ejecución.

## Contexto profesional

C entrega un puntero prestado y Rust asume propiedad completa.

## Objetivo del laboratorio

Definir propiedad, layout, nullability y un wrapper RAII seguro.

## Restricciones y trade-offs

- No liberar buffers ajenos ni crear referencias inválidas.
- Toda afirmación de corrección debe incluir evidencia o describirse como hipótesis.

## Artefacto para inspección

**ffi/bridge.rs · frontera C** (ejemplo didáctico; no salida real del compilador)

```rust
unsafe extern "C" {
    fn open_resource() -> *mut core::ffi::c_void;
    fn close_resource(ptr: *mut core::ffi::c_void);
}
```

**Pregunta del reviewer:** Diseña un wrapper con Drop y explica las garantías del puntero y la thread safety.

## Decisión de diseño

Una API C devuelve un puntero y una función de liberación; ¿cómo lo encapsulas?

- **Opción A:** Almacenar como referencia estática
- **Opción B:** Definir RAII con Drop y contrato de ownership C documentado
- **Opción C:** Llamar free de Rust sin verificar el asignador
